Detailed Operational Workflows

1. Top Navbar Logo Customization Workflow

When a cashier opens an active Point of Sale session, the application automatically inspects `pos.config.enable_pos_logo`. If enabled, the system replaces the default Odoo icon with `/web/image?model=pos.config&id=ID&field=pos_custom_logo` (`Custom Image`) or the company logo (`Company`). If `No Logo` is selected, the header element is cleanly suppressed (`d-none`), providing extra horizontal space for menu buttons.

2. Screen Saver Idle Timer & Watermark Suppression Workflow

The POS client runs a background idle check based on `pos.config.pos_screen_timer` (in minutes). When the terminal registers zero touch/mouse activity for the duration, `SaverScreen` activates. The custom background image or GIF (`pos_screen_saver_image`) renders in full screen with your selected timer color (`pos_timer_color`). Importantly, our patched `wuShowPosLogo` logic checks `enable_screen_saver_bg` and automatically suppresses the default `odoo` SVG watermark across the center of the screen!

3. Custom Receipt Printed Logo (`OrderReceipt`) Workflow

During payment validation, `OrderReceipt` fetches `pos.config.enable_receipt_logo` and `pos.config.receipt_logo_option`. If set to `Custom Image`, the thermal ticket prints your high-resolution receipt logo (`receipt_custom_logo`) at the top of the receipt ticket. If set to `No Logo`, the image container is skipped completely, allowing text-only thermal printing that saves up to 25% on paper roll costs!
