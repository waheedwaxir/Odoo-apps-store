Detailed Operational Workflows

1. Top Navbar Logo Customization Workflow

When a cashier opens an active Point of Sale session, the application automatically inspects `pos.config.enable_pos_logo`. If enabled, the system replaces the default Odoo icon with `/web/image?model=pos.config&id=ID&field=pos_custom_logo` (`Custom Image`) or the company logo (`Company`). If `No Logo` is selected, the header element is cleanly suppressed (`d-none`), providing extra horizontal space for menu buttons.

2. Screen Saver Idle Timer & Watermark Suppression Workflow

The POS terminal runs a background check based on your Screen Timer setting (in minutes). When the cashier registers zero activity for that duration, the Screen Saver activates automatically. Your custom background image or GIF animation is displayed in full screen along with your chosen digital clock font color. Best of all, our smart watermark prevention logic checks your settings and automatically hides the default grey Odoo center watermark!

3. Custom Receipt Printed Logo (`OrderReceipt`) Workflow

During payment validation, the POS system checks your receipt printing preferences. If set to Custom Image, the thermal printer prints your promotional receipt logo header right above the ticket details. If set to No Logo, the header logo is skipped completely, allowing clean text-only thermal printing that saves up to 25% on paper roll costs!
