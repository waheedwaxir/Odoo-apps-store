Enterprise Backend Configuration & Access Rights

Granular Security Groups Matrix (`security/salon_security.xml`)

The module defines 4 distinct security access groups inside Odoo 19 User Settings (`Settings -> Users -> Salon and Spa`). Each role strictly controls what the logged-in user can view, create, edit, or export:

Security Role Intended Staff Role Permissions & Capabilities
No Access / View Only Junior Assistants / Trainees Read-only access to daily timeline schedules. Cannot create, reschedule, or cancel bookings.
User: Create Appointments Receptionists / Front Desk Full management of timeline schedules, customer creation, appointment status updates, and history lookup.
User: Create Payments Cashiers / POS Operators Allows sending appointments to POS, processing payments, capturing employee tips, and marking checkouts as done.
Manager (Full Access) Salon Owners / General Managers Complete administrative control over branch settings, commission rates, tip reconciliation, working hours, and executive reports.

Automated Backend Cron Jobs (`data/cron_jobs.xml`)

To minimize customer no-shows, the module ships with automated Odoo backend cron schedulers that run silently every 15 minutes:

  • Automated 30-Minute Email Reminders: Checks upcoming confirmed bookings and dispatches professional branded reminder emails (`data/mail_templates.xml`) 30 minutes before appointment start time.
  • Automated SMS Gateways: Triggers SMS notification hooks directly to the client's verified mobile phone number.
  • Expired Draft Cleanup: Automatically releases unpaid draft reservations after customizable timeout thresholds.
