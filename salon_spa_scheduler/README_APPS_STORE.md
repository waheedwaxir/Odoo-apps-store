# Salon & Spa Management | Scheduler POS Tips Reports

Price: USD 65

## Short Description
Advanced Salon and Spa Management for Odoo 19 with timeline scheduler, POS integration, customer history, staff tips, memberships, packages, multi-branch **and multi-company** operations and professional reports. Optional website online-booking add-on.

## Main Features
- Advanced branch-wise timeline scheduler
- Customer search by name or phone
- Appointment management with states
- Automatic customer service history
- Service steps and waiting time workflow
- POS payment integration
- Staff tips tracking and paid/unpaid status
- Multi-branch support
- **Multi-company support** – all salon data (branches, chairs, staff, services, packages, memberships, appointments, commissions, tips, reviews, history) is company-scoped with record rules; per-company scheduler working hours, cancellation policy and appointment numbering; shared records (`company = empty`) are visible to every company
- Chairs, rooms and staff configuration
- Membership and loyalty management
- Service packages and combo services
- Employee performance report
- Sales and appointments report
- Dashboard analytics
- Security groups and manager controls

## Package Contents
The product ships as three modules so the Website app is never a forced dependency:

| Module | Install | Purpose |
| --- | --- | --- |
| `salon_spa_scheduler` | You install it | Core application. Depends only on standard apps (POS, HR, Contacts, Product, Stock, Calendar). **No dependency on Website.** |
| `salon_spa_scheduler_website` | Auto-installs **only when the Website app is present** | Customer-facing online booking page (`/salon/booking`) and the "Book Online" website menu. Uninstalling it removes the public page while leaving the core app intact. |
| `salon_spa_scheduler_data` | Optional | Clean, ready-to-use sample data (branches, chairs, staff, services, packages, memberships, customers, appointments, reviews) plus *Import Sample Data* / *Remove Sample Data* menu actions. |
