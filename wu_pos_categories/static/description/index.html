POS Single Line Categories

Maximize POS Screen Space with a Sleek, Horizontal Category Carousel

Replaces the bulky, multi-row category grid in Point of Sale with a compact, modern single-line scrollable bar. Enjoy buttery-smooth touch swipe, mouse drag, mouse wheel navigation, 12 vibrant pastel color accents, and a responsive quick-jump dropdown menu.

Key Capabilities

Why Upgrade Your POS Category Bar?

↔️
Single-Line Horizontal Layout

Replaces multi-line category tiles that occupy 30-40% of the screen. Frees up valuable vertical space so your cashiers see more products at a glance.

🎨
12 Pastel Color Accents

Automatically assigns distinct soft pastel color themes across categories, making it intuitive and lightning-fast for staff to distinguish product groups.

👆
Touch, Drag & Wheel Scroll

Built for both touch screens (tablets, POS terminals) and desktop mice. Supports smooth swipe, click-and-drag, mouse wheel, and left/right navigation arrows.

📋
Quick Overflow Dropdown

Features a clean ellipsis menu button allowing instant access to all categories in a vertical popover list with matching color indicators.

⚙️
Per-POS Configurable

Easily toggle Single-Line Categories ON or OFF from POS Settings for each POS shop independently. Automatically falls back to standard grid if disabled.

⚡
Native Owl 3 Performance

Engineered purely with Odoo 19 Owl 3 reactive architecture. Zero external libraries, zero bloat, instant rendering, and 100% CSP compliant.

Zero Hassle Setup

One-Click Configuration

No complicated parameters or technical knowledge required. Simply navigate to Point of Sale → Configuration → Settings, check the "Single-Line Categories" option, and click Save.

  • ✓ Enabled by default upon installation.
  • ✓ Configurable per POS store/session.
  • ✓ Compatible with standard POS category images.
